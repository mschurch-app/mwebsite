# 雲彩見證圖文編排

## 使用者要求

照片要穿插段落、有大小變化與圖繞文；投稿完成時先編排好，再通知初審。保留投稿原文及附件順序。

## 實作

- `testimony-layout-plan.mjs` 產生版本 1 編排，只保存原文段落範圍與附件 slot／位置／尺寸類型，沒有原文副本或私人聯絡資訊。長段落只在完整句子間分段，不重寫文字；最多 80 個範圍，6000 字的原文仍完整保留。
- `testimony-story-layout.mjs`／CSS 同步至教會 OS。初審、複審、公開閱讀及公開預覽使用同一份編排與相同閱讀樣式。
- 第一張小圖靠右，中段大圖置中，後段較小圖片靠左；依段落長度分散圖片。窄欄改為段落間交錯大小，不把文字擠成過窄欄位。影片保留操作。照片原始比例完整顯示，點擊可另開原檔。
- 短文或純媒體沒有足夠段落時，照片用雙欄組合呈現。所有附件保留，不為了排版省略附件或杜撰圖片說明。
- 閱讀浮窗置中、內部捲動，關閉後回到原按鈕。空資料或 API 不可用時仍保留原本的隱藏公開見證行為。

## 發布關聯

本批官網需與教會 OS 的 `testimony_prepared_layout` migration、投稿 Edge 與審核 UI 一起發布。後端先完成附件檢查、儲存編排，再轉為 pending 並排入初審 LINE。舊投稿由有權限的審核清單入口補齊編排。部署前後應核對官網／教會 OS 的共用檔內容一致。
